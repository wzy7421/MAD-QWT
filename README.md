# MAD-QWT: Informatics-Enhanced Perception in Autonomous Driving

This repository contains the official Python implementation of the Q-factor Wavelet Transform (QWT), Super-Resolution Averaged Projection (SRAP), and Minimum Intensity Projection (MinIP) modules utilized in our autonomous driving perception framework (MAD).

## Project Structure
- `main.py`: The main execution script to reproduce the time-frequency enhancement visualizations.
- `qwt_core.py`: Core algorithms for QWT, SRAP, and MinIP projection strategies.
- `data_utils.py`: Signal preprocessing, FFT, and the Synthetic Signal Generator (described in Appendix A of the paper).
- `requirements.txt`: Python dependencies.
